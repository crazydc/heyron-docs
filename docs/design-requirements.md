## Design Additional Feedback (25/04/2026)

*From Discord chat about the heyron-docs mock site*

### User Flow Vision

Design proposed this flow (agreed with Dale):

```
Home Page (sales) → Signup → Mission Control → Agent Page
                                      ↓
                              Launchpad → Openclaw
```

### Dashboard Contents (Mission Control)

| Section | Description |
|---------|-------------|
| **Quickstart** | Modules 1-8 reconfigured |
| **Tutorials** | Agent Library |
| **Filing Cabinet** | Storage/documents |
| **Fix Agent** | 4 tools + link to support |
| **Account** | User settings |
| **Resources** | External learning |

### Key Points

- ❌ Do away with "TheDenHeyron"
- The heyron.ai/chat page tries to do too much (file cabinet, support, account)
- Don't funnel returning users into same interface as new users
- Need proper structure before handing to agents
- She visualized the design using ChatGPT (public site vs member dashboard)

### Design Design Philosophy

- "Young people don't seem to think in flow charts and tree diagrams"
- Start with visualizations to get dialog going
- Component-driven design — cards should be consistent across all sites
- Match style/colors to original heyron.ai site

## Design Detailed Flow (25/04/2026)

*More detailed version from Discord*

```
HOME
└── Sign Up / Login
    ↓
MISSION CONTROL (Dashboard)

├── 🚀 Your Agent
│   ├── New User → Launchpad → OpenClaw
│   └── Returning → OpenClaw
│
├── ⚡️ Quickstart → GitHub (Quickstart Repo)
├── 📚 Tutorials → GitHub (Tutorials Repo)
├── 🗂 Filing Cabinet (internal)
├── 🛠 Fix Agent → Diagnostics (internal)
├── 💬 Get Help → Discord (external, persistent)
└── ⚙️ Account → Subscription Page

LAUNCHPAD (first-time only)
├── Step 1 → Quickstart
├── Step 2 → Run First Task
├── Step 3 → Join Discord
└── → OpenClaw
```

### Core Principles

1. **Guided path, not a buffet** — Separate pages, linkable, but guided
2. **Top menu + cards** — "Mission Control Look"
3. **Mobile-first** — How people discover the site
4. **Content behind login** — Teasers for public, full content for members
5. **Can link to GitHub** for static content (tutorials, quickstart)
